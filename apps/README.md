# Apps

Production apps are staged under this directory without rewriting application code.

- `core-api`
- `academy-web`
- `academy-api`
- `academy-live`
- `pathway-api`
- `employer-connect-api`
- `economist-app`

Some entries are compatibility symlinks during the skeleton phase. Physical service splits should happen only after CI, Docker contexts, deployment manifests, and security gates are updated in the same change.
